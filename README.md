# CopyToLive Chart — TradingView-like BTCUSD UI

Static, public TradingView-inspired chart workspace for `copytolive/chart`, rebuilt against a 219-screenshot reference set (baseline, top toolbar, drawing tools, right sidebar, bottom bar, dialogs, bar replay and misc controls).

## Public files

- `index.html` — full chart workspace shell
- `styles.css` — responsive TradingView-like light theme
- `app.js` — candlestick renderer + interactions, dialogs, crosshair, zoom/pan, replay, snapshot, save layout and paper-trade drawer
- `.nojekyll` — GitHub Pages compatibility

The initial BTCUSD candle path is deterministic so screenshot parity is stable. This project is independent and is **not affiliated with TradingView**. TradingView is a trademark of TradingView, Inc.
